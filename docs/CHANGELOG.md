## [2.1.0] — 2026-11-17

### ⚡ Комплексный релиз Antigravity Unlocker 2.1: Rust Core, Safe Process Protection, TCP Tuning, V8 Cleaner & Multi-Orchestrator

#### 📋 Список изменённых и созданных файлов:
* `crates/gravity-cli/` — Создано нативное Rust 1.75+ ядро (`Cargo.toml`, `src/main.rs`, `src/patcher.rs`, `src/hosts.rs`, `src/benchmark.rs`, `src/cache.rs`, `src/tcp_tune.rs`) с нулевыми внешними зависимостями рантайма, асинхронным Tokio бенчмаркингом и in-place memory-mapped патчингом.
* `tools/unlocker_core.py` — Реализована интеллектуальная защита процессов `safe_terminate_process` (исключающая случайное завершение текущего IDE/Hub агента), отложенное применение патчей `.pending_patch`, расширенный поиск бинарников через реестр и Scoop, TCP тюнинг и интеграция Планировщика задач.
* `tools/unlocker.py` — Полный рефакторинг в современный CLI-адаптер поверх `unlocker_core.py` с устранением устаревших вызовов NRPT.
* `tools/gui_app.py` — Добавлена кнопка мгновенного перезапуска от Администратора (`🛡️ Перезапуск от Администратора`), обновлены 8 карточек мониторинга (включая TCP-стек, V8 кэш и статус фонового демона).
* `tools/diagnostics.py` — Добавлен сканер живых логов `detect_model_activity`, проверка TCP Auto-Tuning, домен `aicode.googleapis.com` включен во все тесты.
* `tools/proxy_manager.py` & `tools/pin_hosts.py` — Добавлен критический домен `aicode.googleapis.com` для полного устранения утечек локации RU в ответах `FetchConfig`.
* `unlocker.ps1` — Создан native PowerShell-скрипт в соответствии со стандартами `powershell-windows` (ASCII-маркеры, строгая типизация, UAC само-элевация).
* `tools/unlocker.sh` — Создан кросс-платформенный POSIX / Linux / macOS шелл-скрипт (`set -euo pipefail`).
* `Запустить_Анлокер.bat` — Добавлен автоматический запрос повышенных привилегий Администратора (UAC RunAs).
* `Собрать_Rust_Ядро.bat` — 1-click скрипт компиляции Rust-бинарника `gravity-cli.exe`.
* `docs/SYSTEM_ARCHITECTURE.md` — Создана полная архитектурная спецификация системы 2.1.
* `docs/CODE_MAP.md` — Актуализирована структура модулей и функций.
* `docs/RESEARCH_REPORT.md` — Аналитический отчет аудита сторонних решений.

#### 💡 Обоснование изменений:
* Устранена ключевая причина ошибки 403 Forbidden ("User location is not supported") на российских аккаунтах Google: добавлен домен `aicode.googleapis.com` в таблицу hosts-pinning.
* Предотвращен риск самоликвидации активной сессии IDE при вызове патчера за счет умного анализа PID и параметров командной строки (`--hub`, `--app_data_dir`).
* Реализован механизм `.pending_patch`, позволяющий безопасно обновлять бинарники даже в процессе работы IDE.
* Создано сверхбыстрое Rust-ядро (время параллельного бенчмаркинга пула прокси <50 мс, время применения mmap-патча <1 мс).
* Обеспечена автоматическая синхронизация при обновлениях Antigravity через системный Планировщик задач Windows (`schtasks`).

#### 🔄 Сведения о совместимости, миграциях и откате:
* Обратная совместимость: 100% сохранена. Все изменения в `hosts`, сетевом стеке TCP и бинарниках полностью откатываются одной командой (`unlocker.py --restore`, `unlocker.ps1 -Action Rollback` или кнопкой "Откатить все" в GUI).
* Исходные настройки TCP сохраняются в `backups/tcp_state.json`.

## [2.1.0-alpha] — 2026-11-17

### 🔬 Исследование и сравнительный анализ ведущих сторонних аналогов

#### 📋 Список изменённых и созданных файлов:
* `docs/RESEARCH_REPORT.md` — Создан подробный аналитический отчет с детальным разбором архитектуры, сравнительной таблицей и планом переноса лучших практик из `vezlin1/antigravity-bypass-russia`, `confeden/Antigravity` и `trustybird/agy-unlock`.
* `.gitignore` — В исключения добавлена папка `research/` со склонированными репозиториями.
* `docs/CHANGELOG.md` — Зафиксированы результаты аудита и дорожная карта инженерных улучшений.

#### 💡 Обоснование изменений:
* Проведен глубокий технический аудит трех ключевых открытых решений на Rust и Python.
* Выделены ключевые инженерные преимущества для заимствования:
  1. Патч переменной окружения `https_proxy` -> `AG_LS_PROXY` (11 байт в 11 байт) для изоляции проксирования `language_server` без поломки глобальной сети.
  2. Глубокий алгоритм обнаружения установленных копий IDE через реестр Windows (`Uninstall\...\InstallLocation`), Scoop (`scoop/apps`) и `~/.gemini/bin`.
  3. Очистка кэшей V8 (`CachedData`, `Code Cache/js`) после патчинга `main.js`.
  4. Анализ живых ответов модели через логи (`...streamGenerateContent... ResponseID:...`) для отображения честного статуса работоспособности.
  5. Оптимизация сетевого стека TCP Windows (`autotuninglevel=normal`, `fastopen=enabled`).
  6. Фоновый автопатчер при входе в систему через Планировщик Windows (`schtasks`).

#### 🔄 Сведения о совместимости и откат:
* Никаких breaking changes в текущий рантайм `gravity-def` не вносилось.
* Склонированные репозитории размещены в изолированной папке `research/` и исключены из Git.
